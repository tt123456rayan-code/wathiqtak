# وثيقتك MVP

## تشغيل محلي

```powershell
npm run dev
```

## Build

```powershell
npm run build
```

## النشر على GitHub Pages

اسم المستودع المقترح: `wathiqtak`

الرابط المتوقع بعد النشر:

```text
https://USERNAME.github.io/wathiqtak/
```

أوامر التشغيل المحلي:

```bash
npm install
npm run dev
npm run build
```

ملاحظة: القراءة المحلية عبر الويب تجريبية، وأوضاع الهاتف المحلية ضمن خطة Android.

## ملاحظة اختبار العرض

- شغّل التطبيق قبل العرض.
- جرّب OCR مرة واحدة قبل العرض لتحميل ملفات اللغة.
- استخدم مثال “كتاب وزارة الصحة - طلب كشوفات عاجل” كخطة بديلة إذا كانت الصورة غير واضحة.

## خطة OCR المحلي للهواتف

- نسخة الويب: قراءة تجريبية باستخدام OCR داخل المتصفح.
- نسخة Android: المسار الأفضل مستقبلًا باستخدام Native PaddleOCR عبر Paddle Lite أو ONNX Runtime Mobile.
- لا يوجد حد استخدام لأن المعالجة تتم محليًا على جهاز المستخدم.
- لا يتم رفع الصور أو النصوص لأي خادم.
- التحليل بعد OCR يبقى داخل `src/lib/analysisEngine.ts` محليًا.

## Smart Document Capture

- يفحص جودة الصورة محليًا داخل المتصفح قبل OCR.
- يقيس حجم الصورة، الإضاءة، التباين، الحدة، وحجم الملف.
- يساعد الأجهزة الضعيفة والمتوسطة عبر تجهيز صورة أخف قبل القراءة.
- يقلل فشل OCR بإظهار تحذيرات واقتراحات تصوير واضحة.
- لا يتم رفع الصورة لأي خادم ولا يتم تخزينها في `localStorage`.

## وضع صوّر صح

- يفتح كاميرا الهاتف الخلفية قدر الإمكان عبر `capture="environment"`.
- يعرض إرشادات قبل التصوير حتى تكون الورقة واضحة ومقروءة.
- يفحص جودة الصورة محليًا بعد الالتقاط.
- يعطي قرارًا واضحًا: الصورة مناسبة، مقبولة، أو يفضل إعادة التصوير.
- يقلل فشل OCR خصوصًا على الأجهزة الضعيفة والمتوسطة.
