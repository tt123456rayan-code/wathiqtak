# PaddleOCR Models Plan

## الهدف

اختيار نماذج عربية خفيفة تعمل محليًا على Android وتتعامل مع الكتب الحكومية العربية.

## المرشحات

- Detection model خفيف لتحديد مناطق النص.
- Recognition model عربي/متعدد اللغة بحجم مناسب.
- نسخة quantized للأجهزة الضعيفة.
- نسخة balanced لمعظم الأجهزة.
- نسخة أعلى دقة للأجهزة القوية.

## متطلبات النموذج

- يعمل offline.
- لا يحتاج مفاتيح.
- يدعم العربية والإنجليزية للأرقام والمراجع.
- يقبل صور grayscale/contrast enhanced.
- يمكن تشغيله على Paddle Lite أو ONNX Runtime Mobile.

## ملاحظات

الجداول والأختام والترويسات تحتاج تقسيم مناطق قبل OCR، خصوصًا في وضع Lite وBalanced.
