# قائمة حماية الملكية الفكرية

- إبقاء المستودع private.
- توثيق تاريخ التطوير بالـ git commits.
- إضافة اسم صاحب المشروع في `NOTICE.md`.
- تجهيز نسخة إيداع برنامج حاسوب.
- تسجيل اسم وشعار وثيقتك كعلامة تجارية إذا كان متاحًا.
- عدم نشر الكود قبل إجراءات الحماية.
- حفظ نسخة ZIP مؤرخة من الإصدار.
- تجهيز Privacy Policy قبل الإطلاق.
