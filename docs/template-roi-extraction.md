# Template ROI Extraction

هذه خطة لاحقة لتحسين قراءة النماذج الحكومية الجدولية، وليست ميزة مفعلة حاليًا.

## الفكرة

- تعريف قوالب ثابتة للنماذج الحكومية المتكررة.
- قص خانات النموذج حسب مواقع ثابتة داخل الصورة.
- تشغيل OCR لكل حقل منفصل بدل قراءة الصفحة كاملة.
- استخدام OCR أرقام فقط للحقول الرقمية مثل الرقم الوطني، رقم الوثيقة، رقم السند، ورقم الهاتف.
- استخدام OCR عربي للحقول النصية مثل اسم المشتري، اسم البائع، والجنسية.
- مقارنة القيم المستخرجة مع validators محلية قبل عرضها للمستخدم.

## نموذج نقل مركبة

المرحلة الأولى الحالية تعتمد على text parser للنص الناتج من OCR.
المرحلة التالية يمكن أن تضيف خريطة ROI لحقول نموذج نقل المركبة من إدارة ترخيص السواقين والمركبات.

## الخصوصية

كل القص والمعالجة يجب أن تتم على جهاز المستخدم، دون رفع الصور أو النصوص لأي خادم.
